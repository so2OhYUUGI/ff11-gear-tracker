1. フォルダ構成 変更指示書
以下の通りにフォルダを作成し、既存のファイルを移動・リネームしてください。
ステップ A: 新規ディレクトリの作成
まず、src 配下に以下の空フォルダを作成してください。
src/components/layout/
src/components/character/
src/components/gear/
src/app/gear/
src/app/characters/
src/lib/constants/
ステップ B: 既存ファイルの移動
次に、ファイルを移動させます（インポートエラーは後で直します）。
レイアウト関連
src/components/AppHeader.tsx → src/components/layout/AppHeader.tsx
src/components/Navigation.tsx → src/components/layout/Navigation.tsx
キャラクター関連
src/components/CharacterManager.tsx → src/components/character/CharacterManager.tsx

src/components/Dashboard.tsx → 削除、または分割して src/components/gear/ へ
※後ほど JobSelector.tsx や GearSlotList.tsx に分解して再構築します。
